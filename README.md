# CampusMindAI

**Every Campus Problem Deserves a Resolution.**

CampusMindAI is a full-stack campus complaint management platform built to help students report campus issues and enable administrators to track, manage, and resolve them efficiently.

## Features

- Student registration and login
- Secure JWT authentication
- Complaint submission and tracking
- AI-powered complaint classification and analysis
- Duplicate complaint detection
- Complaint priority management
- Admin dashboard and analytics
- Complaint status updates and resolution notes
- Complaint history tracking

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- JWT Authentication

### Frontend
- React
- Vite
- Tailwind CSS
- Recharts
- Lucide Icons
